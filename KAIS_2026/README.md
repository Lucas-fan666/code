# KAIS reproducibility code and data — partial upload

This directory contains analysis and figure-generation scripts, configuration, and a subset of stored results for the KAIS manuscript. The upload is incomplete: large result tables and two processed edge lists are missing. Consequently the experiments cannot yet be fully reproduced from this directory. Consult the complete submission source package for the omitted files. The repository root contains an earlier baseline project. Data origins and applicable source terms are documented in `data/README.md` and `provenance/data_manifest.json`.
