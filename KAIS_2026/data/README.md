# Processed graph inputs

The four supplied edge lists were included in the research package provided for this manuscript. The supplementary experiment removes self-loops, treats edges as undirected, and retains the largest connected component before splitting edges. Their SHA-256 hashes are recorded in `../analysis/supervised_protocol.json`.

- `ca-GrQc.edges`: CaGrQc, <https://snap.stanford.edu/data/ca-GrQc.html>.
- `ca-HepTh.edges`: CaHepTh, <https://snap.stanford.edu/data/ca-HepTh.html>.
- `email-Eu-core.edges`: EmailEuCore, <https://snap.stanford.edu/data/email-Eu-core.html>.
- `p2p-Gnutella08.edges`: P2PGnutella08, <https://snap.stanford.edu/data/p2p-Gnutella08.html>.

The original package's network manifest is in `../provenance/data_manifest.json`. Credit and usage of source data remain subject to the originating dataset's terms.
