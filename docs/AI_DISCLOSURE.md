# Generative-AI disclosure

*The Computer Journal* (Oxford University Press) requires authors to disclose
generative-AI use in the preparation of the manuscript; AI tools cannot be listed
as authors, and the author remains responsible for the content. The manuscript
carries a `Use of generative AI` paragraph in its Declarations section whose text
the authors substitute.

The statement adopted for this submission is given first. Two narrower and broader
alternatives follow: use Version A if the actual use was language editing alone
with no code changes, and Version C only if no generative-AI tool was used at all.

## Adopted statement (matches the manuscript)

> **Use of generative AI.** A large language model was used for two purposes only:
> to edit and proofread the language of the manuscript, and to modify small
> portions of the analysis and figure code. It was not used to design the
> experiments, to generate or interpret the results, or to produce any number
> reported in the paper; every reported value is computed by the released code
> from the released results, and the author reviewed every AI-modified passage
> and line of code and takes full responsibility for the content of the article.

This is the text that appears in the manuscript's Declarations section. It is
deliberately narrower than the version below: it claims language editing and minor
code modification, and makes no claim about AI involvement in drafting the
analysis or the tables.

## Version A -- AI tools used for language editing only

> **Use of generative AI.** The author used a generative AI assistant for
> language editing of the manuscript (improving grammar, clarity and concision).
> No AI tool was used to generate research data, to conduct the experiments, to
> produce the statistical analysis or to create the figures; all results were
> produced by the author's own code, which is released with the paper. The author
> reviewed and edited all AI-assisted text and takes full responsibility for the
> content of the article.

## Version C -- no AI tools used

> **Use of generative AI.** No generative AI tools were used in the preparation of
> this manuscript.

## Policy notes

- **OUP / The Computer Journal.** Disclose generative-AI use in the writing
  process, including the tool and the purpose. AI tools must not be listed as
  authors or coauthors. The statement belongs in the Declarations section, where
  the manuscript already has a placeholder. Check the current OUP author
  guidelines and the COPE position on AI tools on the day of submission; these
  policies are revised frequently.
- **What must be disclosed.** Writing assistance, text generation, translation
  and code assistance used to produce the manuscript or its analysis. Disclosure
  is not a substitute for author responsibility: every number in the paper is
  regenerated from `results/` and every table from `tables/`, and the author must
  be able to defend them.
- **What should not be claimed.** Do not state that "no AI was used" if any
  drafting, code or table assistance occurred. Do not list a tool as an author.
  Do not attribute scientific decisions to the tool; the protocol and
  interpretation are the author'.
- **Consistency.** Use the same wording in the manuscript, the cover letter (if
  it mentions AI) and any repository metadata. The cover letter draft does not
  make an AI claim, so only the manuscript statement needs editing.

The three versions are compatible with the journal's declaration structure. Pick
one, delete the others from the submission copy, and keep this file in the
package for the record.
