# Submission guide

Target venue: **The Computer Journal** (Oxford University Press). The package is
written against a local single-column `comjnl` class shim; at submission the
official OUP class and `compj.bst` replace it. Nothing in the scientific content
or in the numbers changes.

## 1. What the package already satisfies

- `manuscript/main.pdf` builds to **41 pages** from `manuscript/main.tex`.
- **25 tables** and **17 figures**, all generated by scripts; no number is typed
  by hand.
- **64 references** in `manuscript/refs.bib`, **53 with a DOI**; all are cited.
- Structured Declarations section (funding, competing interests, ethics, data
  availability, code availability, author contributions, generative-AI use).
- Single-column layout close to the journal's, with the journal metadata macros
  already wired: `\title[short]`, `\author`, `\affiliation`, `\email`,
  `\shortauthors`, `\received`, `\revised`, `\keywords`.
- Last shim build: zero undefined references, zero undefined citations, zero
  overfull `\hbox` warnings.

The only intentionally missing pieces are author data (`docs/AUTHOR_INFO_PLACEHOLDERS.md`)
and the official class/bst files, which OUP distributes with its author kit.

## 2. The class shim and the official class

`manuscript/comjnl.cls` is **not** the official OUP class. It is a local shim that
reproduces the journal's interface and a single-column layout so that the
manuscript can be compiled and paginated before the author kit is available.
Its header says so explicitly.

At submission:

1. Download the *The Computer Journal* author kit from the OUP journal page
   (or request it from the editorial office).
2. Keep a copy of the shim outside the submission tree if you want to reproduce
   the 31-page pagination later.
3. Put the official `comjnl.cls` and `compj.bst` in `manuscript/`, replacing or
   removing the shim.
4. Change `\bibliographystyle{plainnat}` at the end of `main.tex` to
   `\bibliographystyle{compj}`.
5. Rebuild with four passes (Section 3).

Do not edit the body text to fit the class. If the official class exposes a
different metadata interface, adapt only the preamble/title block, using the
journal's sample file as the reference.

## 3. Build instructions (MiKTeX)

From `manuscript/`:

```bat
pdflatex -interaction=nonstopmode -halt-on-error main
bibtex main
pdflatex -interaction=nonstopmode -halt-on-error main
pdflatex -interaction=nonstopmode -halt-on-error main
```

That is the required four-pass sequence: one LaTeX pass to write `.aux`, BibTeX,
then two more LaTeX passes to resolve cross-references and the bibliography.
MiKTeX may prompt to install `newtx`, `microtype`, `natbib`, `booktabs`,
`subcaption` or `caption` on the first run; allow the installer. TeX Live uses
the same commands.

Before rebuilding after a class swap, delete `main.aux`, `main.bbl`, `main.blg`,
`main.out` and `main.log` so that no stale cross-reference survives.

## 4. Swapping in the official class: step by step

1. **Obtain the kit.** OUP's author instructions page provides `comjnl.cls`,
   `compj.bst` and a sample `.tex`. Network access is required; the files were
   not reachable from the machine on which this package was prepared.
2. **Archive the shim.** Move `manuscript/comjnl.cls` to
   `legacy/comjnl_shim.cls` (or rename it `.bak` outside the manuscript tree).
3. **Install the files.** Copy the official `comjnl.cls` and `compj.bst` into
   `manuscript/`.
4. **Switch the bibliography style.** Replace
   `\bibliographystyle{plainnat}` with `\bibliographystyle{compj}`.
5. **Check the class options.** The current source uses `\documentclass{comjnl}`
   with no options. If the official sample uses an option (for example a
   submission or review mode), adopt the sample's line.
6. **Check the metadata macros.** The body relies on `\title[short]{...}`,
   `\author{...}`, `\affiliation{...}`, `\email{...}`, `\shortauthors{...}`,
   `\received{...}`, `\revised{...}` and `\keywords{...}`. If the official class
   names any of these differently, map them to its interface rather than
   rewriting the front matter.
7. **Check package conflicts.** The shim loads `newtxtext`, `newtxmath`,
   `geometry`, `natbib`, `hyperref`, `microtype`, `booktabs`, `caption`,
   `amsmath`, `graphicx`, `xcolor` and `enumitem`. The official class will load
   some of these itself. Remove a `\usepackage` line only if the log reports an
   option clash; do not remove packages merely because they are also loaded.
8. **Rebuild four passes** and read the log (Section 5).

The header of the shim says "nothing else in `main.tex` needs to change", which
is true for the body. The bibliography style and, possibly, the front-matter
macro names are the two places where the official class can differ.

Why the order matters: `analyze_theory.py` needs `decay_fit.csv` from step 3;
`theory_simulation.py` reads `rules_matrix.csv` (step 7), `theory_gaps.csv`
(step 8) and `noise_calibration.json` (step 9); `analyze_new_experiments.py`
reads all four raw supplementary files plus the calibration. Running
`theory_simulation.py` before `calibrate_noise.py` will fail on a missing JSON.

`scripts/analyze_results.py` also regenerates the tables consumed by the
manuscript, so a full rebuild is: steps 1-14, then the four LaTeX passes.

## 7. The planning tool

`tools/how_much_validation.py` turns a table of per-cell validation and test AUCs
into the near-tie exponent, a noise-limited loss forecast and a budget target.
Requirements are Python 3.9+ with `numpy` and `pandas` only; no network access.

```bat
python tools/how_much_validation.py results/pilot_scores.csv
python tools/how_much_validation.py results/pilot_scores.csv ^
  --sigma-csv results/floor_cells.csv --regime uniform --rho 0.73 ^
  --target 0.01 --json advice.json
```

What it should reproduce on the released example:

- alpha = 0.21 / 0.19 / 0.25 in the three regimes, from `results/pilot_scores.csv`;
- with the measured noise table (`results/floor_cells.csv`), the noise-model
  curve to within 0.001 AUC and a fitted noise exponent of 0.59 / 0.63 / 0.59,
  against 0.53 / 0.63 / 0.58 measured;
- with the default fitted power-law noise scale, a steeper exponent (0.67-0.78).

The tool forecasts the **noise-limited** component only. The measured
distribution-shift floor (0.007-0.011 AUC) is additive to that forecast and no
budget removes it; `tools/README.md` states this and points to Table 5.

## 8. What the author must supply

No placeholders remain. The title page carries the author, affiliation, e-mail and
ORCID iD (0009-0006-9624-385X), and the Declarations section carries the received
and revised dates, the no-funding statement, the competing-interests statement,
the CRediT statement and the AI-use statement. The cover letter carries the date,
the no-funding statement, the ORCID line and an explicit statement that no
reviewer suggestions are made. Nothing in the scientific text, tables, figures or
references is a placeholder. `docs/AUTHOR_INFO_PLACEHOLDERS.md` records the one
thing the editorial office still sets itself, the received/revised stamp.
