## Before submitting to The Computer Journal

1. Download the official `comjnl.cls` and `compj.bst` from the OUP author
   resources for *The Computer Journal* (the class is also mirrored on CTAN).
2. Replace `manuscript/comjnl.cls` with the official class. The local shim
   implements the same interface (`\title[short]{long}`, `\author`,
   `\affiliation`, `\email`, `\shortauthors`, `\received`, `\revised`,
   `\category{}{}{}`, `\terms`, `\keywords`, `\ack`), so `main.tex` should not
   need edits; check the resulting layout anyway.
3. Change `\bibliographystyle{plainnat}` to `\bibliographystyle{compj}` in
   `main.tex` (the last line before `\bibliography{refs}`).
4. Fill the remaining placeholders (`[RECEIVED DATE]`, `[REVISED DATE]`,
   `[CREDIT STATEMENT]`, `[AI DISCLOSURE ...]`, `[FUNDING STATEMENT ...]`,
   `[COMPETING INTERESTS STATEMENT]`) — see
   `../docs/AUTHOR_INFO_PLACEHOLDERS.md`.
5. Rebuild and confirm zero warnings.

## Tables and figures

Tables are `../tables/*.tex` and are `\input` by `main.tex`; figures are
`../figures/*.pdf`, generated by the `scripts/` pipeline. Do not edit the
generated tables by hand — change the analysis script and rerun it, so that the
released artefacts stay in sync with the paper.
