# Writing, retention and dynamical readout of group memory

Source materials for the group-memory writing--readout study. This branch currently contains six recovered Python scripts for figure generation and manuscript building, mechanism definitions, SVG icon assets, citation metadata and dependency versions.

The complete replication archive is `PhysicaA_Zenodo_Code_Data_20261105.zip` (61,202,702 bytes; SHA-256 `9c7e001d81acdfa9b147d8587eb7144bff35f15bd47e4f3f16e4a02a086bf642`). It contains the simulator and analysis sources, all stored result arrays, 64 required strength-analysis input parts, and the full reproduction inputs. The archive passed a clean `python3 reproduce.py --from-data` run.

This branch is a partial source mirror. Use the complete archive from the author or its Zenodo record when published, extract it, and run the reproduction command in its project directory. The scripts in this checkout require the analysis outputs, fonts and manuscript inputs supplied in that archive. The archive DOI will be assigned when the author publishes the deposit.
