## Main text

Place the complete-search subsection immediately after the preserved-law
portfolio-computation subsection. The logical order is: joint-law theorem,
fixed-portfolio computation, then its consequence for a complete adaptive
search. Use the complete-search primary contrast for the application-level
claim, with its exact comparator and the unchanged graphical joint law.

Do not describe finite Monte Carlo non-rejection as quality equivalence.

The new experiment is not a test that FEX is better than NEX. The search
application is held fixed so the implementation contribution can be tested.
The same implementation advantage may be usable by another fresh-tape
adaptive search, but no untested workflow receives a runtime guarantee.
