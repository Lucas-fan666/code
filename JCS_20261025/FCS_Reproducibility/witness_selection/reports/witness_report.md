# 固定最优见证的认证机制优化：独立锁定实验

## 1. 做了什么

只改进回退竞赛的多重比较上界：用一个固定真实最优动作作为证明中的见证，控制其被错误淘汰和错误认证其他动作两类事件。模拟引擎、候选生成、32 条批次、混合下注、筛选的风险对半分配及无效筛选退出规则均保持不变。

筛选版回退阈值从 8.407378 降到 6.327937；不筛选版使用 5.634790。精度 ε=0.1、每查询错误概率上限 α=0.05 均保持不变。完整证明见 theory/witness_bound.md。该结论属于标准固定见证论证的收紧，不声称优先权或最优样本复杂度。

锁定 SHA-256：`60c6238bbb6ed670e8ac382badee85ecdc12f3d403f63b1ddb6bc55aa3468bb4`。时间：2026-10-21T05:46:33.391828+00:00。32 张新图、四族各 8 张、每图 3 条历史，共 96 情境。全部预设比较与所有图均保留；无结果驱动重跑。

**预算变化须单独解释：** 所有方法共同上限改为 32,768 个边际轨迹副本，是此前上限的两倍。机制效果由本轮同预算对照估计；不能把与旧队列的认证率差异全部归因于机制。旧预算列仅记录本轮在耗费不超过 16,384 副本时已认证的情境数，并非独立重跑旧上限。

α=0.05 是每查询错误上限，不是 96 个查询的联合错误上限。

## 3. 失败与不利结果

- mechanism_refinement: 通过预设门槛。质量门=True；校正成本下界=1.15953。
- screen_policy: 未通过预设门槛。质量门=True；校正成本下界=0.95465。
- 此前两轮 94/96、95/96 的失败结论保持有效，不由本轮替换。
- 采用更高共同预算，不能声称在原上限下普遍解决所有认证问题。
- 若几何比值有利，仍应同时查看算术平均和总耗时，不能将其等同为总时间缩减。
- 独立 256 条评估轨迹只能给出噪声评估，不能证明本轮所有认证都正确或估计罕见错误率。
- 本次只覆盖同一固定八动作、一换节点的候选结构，不能外推至所有组合搜索或任意图规模。

## 4. 对论文主张的影响

本轮支持在该预设队列、共同预算和相同认证标准下，相对原筛选实现的成本改善。
筛选相对改进后不筛选竞赛的优势仍未通过门槛，不应把阈值优化收益写成包络筛选的独立收益。
新增理论保证最终返回动作的 ε-精度错误概率；不承诺所有内部成对断言同时正确。这与本实验原有的最终选择质量门一致。它不保证固定预算必然认证，不保证每条随机路径更早停止，也不提升组合目标的近似比。此轮没有改变 FEX/NEX 的历史结果。
